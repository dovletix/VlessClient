# VlessClient

Простой VPN-клиент для подписок VLESS под Windows. Одна большая кнопка «включить / выключить», сам выбирает быстрый сервер, сам включается при запуске компьютера. Для тех, кому нужно больше, — раздельное туннелирование по программам и сайтам, скорость по каждой программе и проверка серверов.

## Установка

1. Откройте страницу [Releases](https://github.com/dovletix/VlessClient/releases/latest) и скачайте файл `VlessClient-<версия>-x64.msi`.
2. Запустите его и нажмите «Установить». Windows спросит разрешение — согласитесь.
   - Если появится синее окно «Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**. Так Windows реагирует на любые программы без платной цифровой подписи.
3. Откроется VlessClient. Вставьте ссылку на подписку (её даёт тот, кто выдал вам доступ к VPN) и нажмите **Подключить**. Если ссылка уже скопирована, она подставится сама.

Всё. Дальше VPN включается сам при каждом запуске компьютера, если вы его не выключили.

## Как пользоваться

- **Большая кнопка** включает и выключает VPN. Зелёная — VPN работает, серая — выключен, жёлтая — подключается, красная — нет связи (клиент сам пробует снова).
- **Значок рядом с часами** показывает то же состояние. Щелчок открывает окно. Закрытие окна крестиком не выключает VPN.
- **Настройки**: выбор сервера, обновление списка серверов, смена ссылки, российские сайты напрямую, обновления, отчёт для помощи.
- **Для продвинутых**: правила для программ (через VPN или напрямую), сайты и адреса, скорость и трафик каждой программы, проверка всех серверов, режим работы.

### Если что-то не работает

**Настройки → Помощь → Сохранить отчёт на Рабочий стол** — и отправьте файл тому, кто помогает вам с VPN. Ссылка на подписку в отчёт не попадает.

## Что умеет

- **Сам выбирает сервер.** При подключении проверяет все серверы подписки настоящим соединением и берёт самый быстрый из работающих, а не «самый первый в списке». Неработающие (например, заблокированные вашим оператором) пропускает. У выбранного сервера всегда есть запасной.
- **Не оставляет за собой сломанный интернет.** VlessClient не трогает настройки прокси Windows. Если VPN или служба падают, туннель исчезает вместе с ними, и интернет работает напрямую. Прокси, брошенный другими VPN-программами (например, Happ), из-за которого не открываются сайты, VlessClient находит и выключает сам.
- **Российские сайты — напрямую**, заблокированные в России — через VPN. Отключается в настройках.
- **Раздельное туннелирование**: любая программа — через VPN или напрямую; любой сайт или адрес — через VPN или напрямую. Применяется сразу, без переподключения.
- **Удалённый доступ не ломается**: RustDesk, AnyDesk и TeamViewer по умолчанию идут напрямую.
- **Два способа работы** (Для продвинутых → Режим): **весь компьютер** через туннель с правилами или **только выбранные программы** без туннеля — тогда остальные программы VlessClient вообще не трогает.
- **Локальный прокси** SOCKS5 + HTTP на `127.0.0.1:12080` для программ, которые умеют работать через прокси.
- **Подписки**: VLESS с Reality, TLS, XHTTP, WebSocket, gRPC, HTTPUpgrade, пост-квантовым шифрованием — всё, что умеет Xray. Самоподписанный сертификат сервера подписки распознаётся автоматически.
- **Соседство с рабочим VPN**: частные сети (10.x, 172.16–31.x, 192.168.x) не заворачиваются в туннель, DNS рабочего VPN не перехватывается.

## Режим «только выбранные программы»

Для тех, кому нужно, чтобы VPN касался только нескольких программ (Discord, Telegram, браузер), а всё остальное — игры, рабочий VPN, торренты — шло как без VPN, мимо VlessClient.

1. **Для продвинутых → Режим → Только выбранные программы.**
2. **Для продвинутых → Программы**: у нужных программ включите «через VPN». Включение и выключение работают сразу.

Как это устроено: трафик выбранных программ (TCP и UDP, то есть и звонки) перехватывает [ProxiFyre](https://github.com/wiresock/proxifyre) на драйвере [Windows Packet Filter](https://github.com/wiresock/ndisapi) и передаёт его VlessClient. При первом включении режима VlessClient скачивает оба компонента с их официальных страниц на GitHub (закреплённые версии, проверка SHA-256; загрузка идёт через уже работающий VPN) и тихо ставит. При удалении VlessClient убирает их, если ставил сам.

Что важно знать:
- Другие программы не затрагиваются совсем: ни туннеля, ни маршрутов.
- IPv6 выбранных программ блокируется, они переходят на IPv4 — так ничего не утекает мимо VPN.
- Когда VPN выключен, перехват выключается тоже: у выбранных программ остаётся обычный интернет.
- Нужна среда Microsoft Visual C++ 2015–2022 (64-бит); если её нет, VlessClient поставит её с сайта Microsoft.
- Некоторые античиты (FACEIT, Vanguard) могут ругаться на сетевые драйверы. Для таких игр используйте режим «весь компьютер».
- В таблице «Программы» трафик выбранных программ показан одной строкой «Выбранные программы».

Почему не WinDivert (на нём работает zapret): Microsoft Defender с защитой от нежелательных программ удаляет даже официальный архив WinDivert. Windows Packet Filter подписан и Defender его не трогает.

## Обновление

**Настройки → Обновления → Проверить обновления**, затем **Обновить**. Обновление ставится само, без вопросов Windows; VPN отключается примерно на полминуты, настройки сохраняются.

Автоматическое обновление выключено по умолчанию; его можно включить там же — тогда VlessClient раз в 12 часов проверяет новую версию и ставит её сам.

## Удаление

**Параметры Windows → Приложения → VlessClient → Удалить.** Удаляются программа, служба, настройки, ярлыки и автозапуск; туннель и прокси за собой не остаются. Если включался режим «только выбранные программы», через минуту после удаления VlessClient уберёт и ProxiFyre с драйвером (если ставил их сам).

## Требования

- Windows 10 (1803 и новее) или Windows 11, 64-бит. .NET Framework 4.8 уже есть в этих системах.
- Ссылка на подписку с серверами VLESS.

## Как это устроено

```
программы ──► туннель VlessClient (sing-box)
                 ├─ правила: программы / сайты / адреса / российские сайты
                 ├─ напрямую ──► ваш интернет
                 └─ через VPN ──► xray ──► сервер VLESS
```

- **Служба Windows «VlessClient VPN»** (от имени системы) держит подключение, выбирает сервер, следит за ядрами и перезапускает их. Ядра работают в объекте задания Windows: если служба завершится, они завершатся вместе с ней.
- **Окно и значок в трее** работают от обычного пользователя и управляют службой через именованный канал.
- **Ядра**: [sing-box](https://github.com/SagerNet/sing-box) делает туннель и правила, [Xray-core](https://github.com/XTLS/Xray-core) подключается к серверам VLESS. Обе программы входят в установщик без изменений.
- **Настройки** лежат в `C:\ProgramData\VlessClient\settings.json` (менять их может только служба или администратор); логи — в `C:\ProgramData\VlessClient\logs`. Тонкие настройки (порты, DNS, рабочий VPN Check Point) есть только в этом файле; после правки перезапустите службу VlessClient.

## Сборка из исходников

Нужны Windows x64 и .NET SDK 8 или новее.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File installer\build-msi.ps1 -Version 2.0.0
```

Готовый MSI появится в `installer\dist`. Скрипт скачивает ядра с официальных релизов и проверяет их SHA-256 (версии закреплены в `cores.ps1`).

Публикация: тег вида `v2.0.1` запускает GitHub Actions, который собирает MSI и создаёт релиз — из него приложение и берёт обновления.

## Консольная версия

В папке `legacy/` лежит прежняя версия на PowerShell — команда `vpn` с замером качества UDP для голоса (`vpn quality`), диагностикой маршрутов (`vpn doctor`) и прочим. Она не связана с MSI-версией и не нужна обычным пользователям. Не запускайте обе одновременно: два туннеля мешают друг другу.
