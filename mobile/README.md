# VlessClient для телефона (Android и iOS)

Та же идея, что у VlessClient для Windows: большая кнопка «включить / выключить», быстрый сервер выбирается сам, российские сайты идут напрямую. Для тех, кому нужно больше, есть правила для приложений и сайтов, скорость и трафик каждого приложения, соединения без ответа и проверка серверов. Оформление то же, что в Windows-версии: тёмное по умолчанию, светлое — в настройках.

## Android

1. Откройте [страницу выпусков](https://github.com/dovletix/VlessClient/releases) и найдите самый новый выпуск «VlessClient для телефона». Скачайте `VlessClient-<версия>-arm64-v8a.apk` — он подходит почти всем телефонам. Если не уверены, скачайте `…-universal.apk`: он больше, но работает везде.
2. Откройте файл на телефоне. Android попросит разрешить установку из этого источника (браузера или «Файлов») — разрешите.
3. Откройте VlessClient, вставьте ссылку на подписку и нажмите **Подключить**. Android спросит разрешение на VPN — согласитесь.

Чтобы VPN включался сам после перезагрузки, включите для VlessClient **«Постоянная VPN»**: Настройки Android → Сеть и интернет → VPN → значок шестерёнки рядом с VlessClient. Обновления: **Настройки → Проверить обновления** в самом приложении.

Включать и выключать VPN можно, не открывая приложение: опустите шторку уведомлений, нажмите карандаш (изменить кнопки) и перетащите плитку **VlessClient** к остальным. Плитка включает последний выбранный сервер; при самом первом запуске она открывает приложение, чтобы Android спросил разрешение на VPN.

## iPhone и iPad

Приложение для iOS собирается вместе с Android-версией, но поставить его просто так нельзя. Apple даёт приложениям право создавать VPN только при подписи платным аккаунтом разработчика (99 $ в год). Бесплатный Apple ID через AltStore или Sideloadly этого права не даёт. В App Store России VPN-приложения Apple удаляет по требованию властей.

Поэтому для iPhone есть два пути:

- **Свой аккаунт разработчика.** В выпуске есть файл `VlessClient-<версия>-ios-unsigned.ipa`: его можно подписать своим аккаунтом и поставить через Xcode или TestFlight. Идентификаторы приложения — `io.github.dovletix.vlessclient` и `io.github.dovletix.vlessclient.PacketTunnel`, группа приложений — `group.io.github.dovletix.vlessclient`; их нужно завести в своём аккаунте с правом Network Extension (Packet Tunnel).
- **Готовые клиенты из App Store других стран** (Streisand, V2Box, Happ, sing-box), куда вставляется та же ссылка на подписку.

## Что умеет

- **Главная**: кнопка, текущий сервер, время подключения, скорость загрузки и отдачи.
- **Программы** (Android): правила «всегда через VPN» и «всегда напрямую» для выбранных приложений. Ниже — активность каждого приложения: скорость, объём, сколько трафика ушло через VPN и сколько напрямую.
  - Нажатие на строку раскрывает адреса, куда ходит приложение, с маршрутом и скоростью по каждому, и **соединения без ответа**: время, адрес, маршрут, причина (таймаут, отказ, сброс, адрес не найден, UDP). Ниже — подсказка, что попробовать.
  - Долгое нажатие коротко показывает, куда ходит приложение (в Windows-версии это всплывает при наведении).
  - Есть поиск, фильтр «только с проблемами», сортировка и сброс статистики.
  - На iOS система не сообщает, какое приложение открыло соединение, поэтому весь трафик собран в одну строку «Все приложения».
- **Сайты**: списки «всегда напрямую» и «всегда через VPN», адреса и подсети (`1.2.3.0/24`), переключатель «российские сайты напрямую».
- **Серверы**: автоматический выбор или конкретный сервер (у выбранного вручную есть запасной на случай сбоя), проверка всех серверов, исключение медленных серверов из автовыбора. Кнопка **Проверить** работает и при выключенном VPN: телефон проверяет серверы сам, без туннеля (значок VPN не появляется, другие приложения это не затрагивает). Так удобно понять, какие серверы доступны через мобильную сеть, ещё до подключения.
- **Настройки**: подписка и запасные подписки, куда идёт остальной трафик, QUIC, включение при запуске, тема, обновления (Android), отчёт для помощи. Запасная подписка выручает, если основная не загружается или ни один её сервер не отвечает: тогда приложение берёт серверы из запасной. Подойдёт та же подписка по другому адресу или подписка другого сервиса; одинаковые серверы не дублируются.

### Отличия от Windows-версии

- Основное ядро на телефоне — sing-box. Серверы с транспортом **XHTTP** и с шифрованием VLESS (mlkem) он не поддерживает, поэтому на Android с версии 1.0.1 их везёт встроенный Xray. Он есть в сборках `arm64-v8a`, `x86_64` и `universal`; в списке серверов такие помечены «через Xray». На 32-битных телефонах (`armeabi-v7a`) и на iOS Xray нет, там эти серверы серые и в выборе не участвуют.
- С версии 1.0.2 через встроенный Xray идут и все серверы **Reality**. Сервер на Xray 26.9.8 и новее (свежие панели 3x-ui обновляются сами) отвергает подключение Reality от sing-box: sing-box пока не присылает нужный ключ X25519MLKEM768 ([SagerNet/sing-box#4520](https://github.com/SagerNet/sing-box/issues/4520)). На iOS и `armeabi-v7a` такие серверы не подключатся, пока это не исправят в sing-box.
- Статистика собирается, пока открыто приложение. Совсем короткие соединения, которые успели открыться и закрыться между двумя опросами (раз в секунду), в подсчёт могут не попасть, как и в Windows-версии.

## Сборка

Всё собирается в GitHub Actions (`.github/workflows/mobile.yml`): библиотека sing-box (libbox) для Android и iOS, базы российских сайтов, APK и неподписанная сборка для iOS. Метка `mobile-v1.2.3` публикует выпуск. Локально нужен Flutter (версия указана в workflow): `flutter analyze` и `flutter test` работают без Android SDK. Для `flutter build apk` нужны Android SDK и `android/app/libs/libbox.aar` из артефактов CI.
